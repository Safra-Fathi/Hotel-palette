Hotel Palette
Hotel Palette is a modern hotel booking system designed to provide a seamless 
experience for guests. The system allows users to browse various room types, check 
availability, and make reservations efficiently. It includes key features such as room 
filtering, promotions, and a user-friendly interface to enhance the booking experience.
Additionally, Hotel Palette integrates Data Structures and Algorithms (DSA) to optimize 
performance. Features like bubble sort for sorting rooms, priority queues for ranking 
rooms based on user preferences, and spanning trees for efficient network 
management contribute to its efficiency. The system ensures clarity in design, smooth 
user interactions, and reliable functionalit

This page lists various room types, including Double Room, Single Room, Family 
Room, Luxury Room, and King Room, each displayed with high-resolution images, 
descriptions, and a View Details button that directs users to more information.
1. Search and Filter Functionality
a. Users can easily search for rooms using a search box that filters results 
in real time.
b. This search feature is implemented using a linear search algorithm, 
which checks each room name against the user’s query and dynamically 
updates the display.
2. Sorting Mechanism with Bubble Sort
a. To improve organization, rooms are sorted alphabetically using a 
Bubble Sort algorithm when the page loads.
b. This ensures a structured and user-friendly display, making it easier for 
guests to browse through the available options.
